# Documentation versions

The main navigation contains the current, canonical Edge Core documentation.
It describes the supported V2 product line and is updated alongside the
codebase.

V3 documentation will replace it only when the V3 product contract is complete.
At that point, the V2 documentation will be frozen as an immutable archive and
the new V3 documentation will become canonical.

| Version | Status | Documentation source |
| --- | --- | --- |
| [V2](v2.md) | Current supported line | This documentation site |
| [V3](v3.md) | In development | Published when its contract is complete |

The Core documentation version and an individual API specification version are
separate concepts. For example, OpenAPI and AsyncAPI artifacts retain their
own compatibility versions within a Core documentation line.
